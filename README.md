# fin-mgmt-app
I wanted to help my parents organize their outcome sources so I decided to code a small tool to help them out while practicing python


## Initial idea
I made a simple command line script that contained a main function which served as a starting point to what I wanted the program to do, in this case it can register, list, and sum money spending across different movements.

I added a new function that could also show spending by category, so it makes it easier to track in a more general way how is the money spent
